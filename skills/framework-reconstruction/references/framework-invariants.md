# Framework Invariants

## Purpose

This reference identifies what should survive reconstruction unless settlement evidence disproves it. It keeps doctrine revision from dissolving the distinctions that make the harness legible.

## Decision Rules

- The framework is subject to settlement.
- Preserve distinctions between potential, possibility, affordance, capability, and substrate unless evidence shows the distinction itself has failed.
- Preserve settlement over intent.
- Preserve horizon expansion over outcome worship.
- Preserve positive disintegration as selective salvage rather than indiscriminate destruction.

## Enterprise Notes

- Reconstruction should generate a new falsification surface, not just new wording.
- Record which invariants were preserved and why so future audits can tell doctrine revision from doctrinal drift.
- Enterprise operators need a stable vocabulary even when policy or workflow details evolve.

## Failure Modes

- Rewriting the framework without falsifying the existing one.
- Preserving failed doctrine because it is familiar.
- Throwing away core distinctions together with contingent implementation details.
- Declaring the new reconstruction complete without a new settlement plan.

Use this reference to preserve the doctrine's core distinctions while revising failed structure.
